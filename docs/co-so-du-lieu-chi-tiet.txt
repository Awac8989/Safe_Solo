SAFE SOLO - MO TA CHI TIET CAC CO SO DU LIEU
Ngay cap nhat: 2026-05-12

========================================================================
1. TONG QUAN HE THONG DU LIEU
========================================================================

Hien tai SafeSolo su dung MongoDB la nguon du lieu chinh cho backend.

Thong tin ket noi mac dinh:
- He quan tri: MongoDB
- Database name: Safesolo
- Connection string mac dinh: mongodb://127.0.0.1:27017/Safesolo

Ngoai MongoDB, he thong con co:
- SharedPreferences tren app Flutter de luu session, ngon ngu, state cuc bo.
- Thu muc uploads cua backend de luu tep tai len nhu giay to KYC hoac am thanh.
- Cac file cau hinh .env / env local de luu khoa va URL, khong phai co so du lieu.

MongoDB la noi luu tru nghiep vu chinh cho:
- nguoi dung
- check-in
- canh bao SOS
- guardians
- ho so y te
- KYC
- chat
- community feed
- vault
- dieu phoi admin

-----------------------------------------------------------------------
3.1. Collection: users
-----------------------------------------------------------------------
Muc dich:
- Luu ho so nguoi dung chinh cua he thong.
- Day la collection trung tam lien ket den hau het collection khac.

Khoa chinh:
- _id: string UUID

Truong quan trong:
- fullName: ho ten
- phoneNumber: so dien thoai, unique
- role: user hoac admin
- email
- avatar
- firstName, lastName
- dateOfBirth
- gender
- isActive
- isVerified
- isKycVerified
- otpCode, otpExpiresAt
- lastLoginAt
- highContrast
- pillReminder, pillTime
- realPin, duressPin
- trustScore
- rescuesCount
- batteryLevel
- approxAddress
- medicalNotes
- emergencyContacts[]: danh sach lien he khan cap
- timerIntervalMinutes: chu ky check-in
- lastCheckinTime
- nextDeadline
- currentStatus: SAFE / REMINDER / WARNING / SOS
- lastKnownLocation: lat / lng / updatedAt
- lastReminderAt, lastWarningAt, lastSosAt
- quietHoursStart, quietHoursEnd
- sleepModeUntil
- falseAlertGraceMinutes
- deadmanStage
- deadmanEscalationTriggeredAt
- createdAt, updatedAt

Quan he:
- 1 user co the co 1 medicalprofiles
- 1 user co the co 1 securitysettings
- 1 user co the co 1 automationsettings
- 1 user co the co 1 alertpolicies
- 1 user co the co nhieu checkinhistories
- 1 user co the co nhieu interactionevents
- 1 user co the co nhieu alertevents
- 1 user co the co nhieu devicesignals
- 1 user co the co 1 vaults
- 1 user co the co 1 kycdocuments
- 1 user co the tao nhieu dailystatuses, messages, thankyounotes

- co 1 alertpolicies
- co 1 vaults
- co 0..1 kycdocuments
- co nhieu guardianrelationships
- co nhieu checkinhistories

- co nhieu devicesignals
- co nhieu dailystatuses
- co nhieu messages
- co nhieu emergencylogs

- co nhieu volunteerresponses neu la hiep si

1 rescueincidents
- co nhieu volunteerresponses
- co 1 chatrooms dang roomType = INCIDENT
- co nhieu emergencymemos
- co systemlogs lien quan

1 emergencylogs
- co nhieu smsdispatchlogs

========================================================================
5. CAC NGUON LUU TRU NGOAI MONGODB
========================================================================

5.1. SharedPreferences trong Flutter
Duoc dung de luu:
- session user
- ngon ngu
- theme / high contrast
- mot so cache UI cuc bo

5.2. Uploads tren backend
Thu muc uploads duoc dung cho:
- anh KYC
- giay to mat truoc / mat sau
- tep ghi am hoac media neu backend luu file

5.3. Env config
Khong phai co so du lieu, nhung la noi luu:
- MONGODB_URI
- MONGODB_DB_NAME
- JWT_SECRET
- MAPTILER_KEY

========================================================================
6. DONG DU LIEU NGHIEP VU QUAN TRONG
========================================================================

6.1. Check-in
- App Flutter gui check-in
- users.lastCheckinTime duoc cap nhat
- users.nextDeadline duoc tinh lai
- checkinhistories them ban ghi moi
- interactionevents ghi log CHECK_IN

6.2. Dead-man switch
- Worker doc users + alertpolicies + securitysettings
- Neu qua han se tao alertevents
- Neu can se tao emergencylogs va smsdispatchlogs

6.3. SOS cong dong
- Tao rescueincidents
- Volunteer nhan ca -> volunteerresponses
- He thong tao / dong bo chatrooms
- Tin nhan vao messages
- Voice memo vao emergencymemos

6.4. KYC
- User nop giay to -> kycdocuments
- Admin duyet -> users.isKycVerified = true
- Sau do volunteer moi duoc nhan ca cuu ho

========================================================================
7. CAC DIEM CAN CHU Y KHI PHAT TRIEN TIEP
========================================================================

- Nen giu userId dang string UUID de khong gay API Flutter va web-admin.
- Cac collection lien quan safety can uu tien index theo:
  userId, incidentId, createdAt, status.
- Cac URL file trong KYC va voice note nen tach ro:
  local uploads / cloud object storage.
- Neu mo rong analytics, nen them collection tong hop hoac worker summary rieng,
  khong query truc tiep cac collection lon qua nhieu tren dashboard.

========================================================================
8. KET LUAN
========================================================================

Co so du lieu hien tai cua SafeSolo xoay quanh MongoDB database "Safesolo".
Collection trung tam la users. Tu day he thong mo rong ra:
- an toan va check-in
- canh bao va SOS
- y te va bao mat
- KYC va hiep si
- chat va cong dong
- dieu phoi admin

File nay duoc tao de phuc vu:
- tai lieu du an
- onboarding lap trinh vien
- nghiep vu cho admin va product
- tham chieu khi mo rong backend, app va web-admin
